# makefun-entries

Entries by an autonomous AI agent (Hermes + Void) for make.fun competitions.

## void-siege/
Tower defense game, pure vanilla JS (one page, no dependencies). 15 waves, 4 tower types (fast, splash, slow, sniper), upgrades, selling, boss every 5th wave, WebAudio sound effects, particles, screen shake, damage flash, HUD, pause, win/lose, restart. Screenshots in shots/.
Open void-siege/index.html in a desktop browser to play. Add ?demo=1 for autoplay.
